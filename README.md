# SUHOOL TECH Portal

بوابة سهول تيك للأنظمة الإدارية والتقنية.

## الحالة الحالية
النسخة الأولى هي أساس واجهة البوابة (Frontend foundation) وتشمل:
- هوية بصرية مستوحاة من شعار سهول تيك.
- لوحة رئيسية متجاوبة.
- دعم العربية RTL والإنجليزية LTR.
- بطاقات الأنظمة وحالات الإتاحة.
- بحث محلي في الأنظمة والتنقل الجانبي.

## الأنظمة المخطط لها
- المهام والمشاريع.
- عروض الأسعار.
- الموارد البشرية.
- المسودات والمستندات.
- الخدمات الإدارية.
- خزنة كلمات المرور (بمتطلبات أمنية مستقلة).

## التشغيل محلياً
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

- هذه الواجهة مرحلة تأسيسية ولا تتضمن حتى الآن مصادقة حقيقية أو قاعدة بيانات أو صلاحيات خادمية.
- أرقام البطاقات وحالة الأنظمة في الواجهة تعريفية وليست بيانات تشغيلية.
