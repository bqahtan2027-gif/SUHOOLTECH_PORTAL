# SUHOOL TECH Portal

بوابة سهول تيك الموحدة لإدارة أعمال الشركة، بواجهة عربية أولاً ودعم الإنجليزية.

## Product direction
راجع [خارطة المنتج](docs/PRODUCT_BLUEPRINT.md) لمعرفة الوحدات المقترحة ومراحل التسليم، و[سياسة الأمان](SECURITY.md) لمتطلبات حماية البيانات.

## Current foundation
- React + TypeScript + Vite.
- هوية بصرية مستوحاة من شعار سهول تيك.
- واجهة متجاوبة ودعم RTL/LTR.
- مخطط تأسيسي لـ PostgreSQL/Supabase في `supabase/migrations`.
- أساس عزل المؤسسات والأدوار والصلاحيات (RLS/RBAC).
- نماذج أولية لـ CRM والمشاريع والمهام وعروض الأسعار والموارد البشرية والمستندات والطلبات والأصول والإشعارات وسجل التدقيق.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Backend setup status
لم يتم ربط المشروع بمثيل Supabase بعد. قبل إدخال بيانات حقيقية:
1. أنشئ مشاريع منفصلة للتطوير والاختبار والإنتاج.
2. راجع ملفات SQL ثم طبّقها على قاعدة بيانات جديدة.
3. أضف تدفقاً خادمياً موثوقاً لإنشاء المؤسسة وأول مدير وتعيين الأدوار.
4. أكمل سياسات تخزين الملفات، التسجيل التدقيقي، الدعوات، MFA، والاختبارات الأمنية.
5. أضف متغيرات `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` إلى بيئة التشغيل؛ لا تضع مفاتيح الخدمة في الواجهة الأمامية.

## Important
- لا توجد حالياً مصادقة إنتاجية أو بيانات حية أو عمليات خلفية متصلة.
- لا تعتبر أي بطاقة إحصائية أو حالة نظام بيانات فعلية ما لم تكن موصولة بمصدر موثوق.
- لا تحفظ كلمات مرور أو مفاتيح تشفير أو أسراراً في Git أو المتصفح بصيغة مكشوفة.
- خزنة كلمات المرور تحتاج تشفيراً من جهة العميل ومراجعة تهديدات مستقلة قبل إطلاقها.
