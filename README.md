# SUHOOL TECH Portal

بوابة سهول تيك المستقلة لإدارة أعمال الشركة. لا تتطلب Supabase أو Firebase أو خدمات SaaS خارجية.

## البنية الحالية
- واجهة React + TypeScript + Vite بتصميم عربي RTL ودعم الإنجليزية.
- API مستقل باستخدام Node.js وExpress.
- PostgreSQL لتخزين بيانات الشركة.
- تسجيل دخول بكلمات مرور مشفرة باستخدام bcrypt وJWT قصير العمر.
- تهيئة أول مدير برمز لمرة واحدة.
- إدارة المشاريع والمهام: الإنشاء والعرض وتحديث الحالة.
- مؤشرات مباشرة للوحة التحكم وسجل تدقيق للأحداث الأساسية.
- Docker Compose وNginx متاحان للخوادم الخاصة فقط، وليس لخطة Shared W500.

## النشر

- **خادم خاص/VPS:** راجع [دليل الاستضافة الذاتية](SELF_HOSTING.md).

## التطوير المحلي
1. شغّل PostgreSQL.
2. طبّق بالترتيب `database/init/001_core.sql` ثم `database/init/002_projects_dashboard.sql`.
3. شغّل API من مجلد `server` بعد ضبط متغيرات البيئة.
4. في جذر المشروع شغّل `npm install` ثم `npm run dev`. يمرر Vite طلبات `/api` إلى `http://127.0.0.1:4000`.

## التحقق
يوجد GitHub Actions workflow لبناء واجهة React وفحص صياغة API عند الدفع أو فتح Pull Request.

## ملاحظات الإطلاق
هذه نسخة تشغيل أولية وليست منصة مؤسسية مكتملة بعد. الوحدات التي لم تُربط بعمليات خلفية حقيقية تبقى قيد التطوير. قبل استخدام بيانات الشركة الفعلية، أكمل MFA، دعوات المستخدمين واستعادة الحساب، صلاحيات دقيقة لكل وحدة، سجل تدقيق شامل، النسخ الاحتياطي والاستعادة، HTTPS، المراقبة، واختبارات أمنية مستقلة. لا تضع ملف `.env` أو كلمات المرور أو مفاتيح التشفير في Git.
