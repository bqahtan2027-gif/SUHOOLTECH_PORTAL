# SUHOOL TECH Portal

بوابة سهول تيك المستقلة لإدارة أعمال الشركة. تعمل على خادم الشركة الخاص ولا تتطلب Supabase أو Firebase أو قاعدة بيانات سحابية خارجية.

## الحزمة الحالية
- واجهة React + TypeScript + Vite بتصميم عربي RTL ودعم الإنجليزية.
- API مستقل باستخدام Node.js وExpress.
- قاعدة بيانات PostgreSQL مستضافة على نفس بيئة Docker.
- تسجيل دخول بكلمات مرور مشفرة باستخدام bcrypt وJWT قصير العمر.
- إنشاء أول مدير من خلال رمز تهيئة لمرة واحدة.
- إدارة أولية للمهام: الإنشاء وعرض القائمة وتحديث الحالة.
- Docker Compose وNginx للنشر على خادم خاص.

## التشغيل على الخادم
راجع [دليل الاستضافة الذاتية](SELF_HOSTING.md). انسخ `.env.selfhost.example` إلى `.env`، عيّن أسراراً قوية، ثم شغّل:
```bash
docker compose up -d --build
```

## التطوير المحلي
- شغّل PostgreSQL محلياً وطبّق `database/init/001_core.sql`.
- شغّل API من مجلد `server` بعد ضبط متغيرات البيئة.
- في جذر المشروع شغّل `npm install` ثم `npm run dev`. يمرر Vite طلبات `/api` إلى `http://127.0.0.1:4000`.

## ملاحظات الإطلاق
هذه نسخة تشغيل أولية وليست منصة مؤسسية مكتملة بعد. الوحدات التي لم تُربط بعد بعمليات خلفية حقيقية يجب أن تبقى قيد التطوير. قبل استخدام بيانات الشركة الفعلية، أكمل MFA، دعوات المستخدمين واستعادة الحساب، صلاحيات دقيقة لكل وحدة، سجل تدقيق شامل، النسخ الاحتياطي والاستعادة، HTTPS، المراقبة، واختبارات الاختراق. لا تضع ملف `.env` أو كلمات المرور أو مفاتيح التشفير في Git.
